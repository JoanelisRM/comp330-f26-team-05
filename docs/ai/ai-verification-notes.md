# AI Verification Notes

**Owner:** Nova (AI/Governance Lead) | **Backup:** Hamza

## Verification Notes

*(Note: No significant AI verification notes have been required for Phase A1 - Project Launch. Future verification notes for complex implementation or architecture decisions will be appended below using the AVN-### format.)*

## When to Create a Verification Note

A separate verification note is especially useful when AI materially contributes to security-sensitive code, authentication, data integrity logic, significant architectural decisions, complex algorithms, or phase-gate evidence.

## Verification Independence

AI may assist in verification, but meaningful verification should include independent human judgment and appropriate external evidence.

## Verification Depth

The depth of verification should be proportional to the potential consequence of accepting incorrect AI output.

## Verification Against Requirements

Where AI-assisted work implements or affects system behavior, verification should reference the applicable requirements and acceptance criteria when practical.

## Failed Verification Is Valuable Evidence

Record the result when the failure is significant enough to affect project history or engineering decisions. A failed verification may demonstrate excellent engineering judgment.

## Expectations

- Create verification notes for significant AI-assisted work when detailed evidence is warranted.
- Use unique `AVN-###` identifiers.
- Link entries to the AI Use Log and related engineering evidence.
- Describe the AI contribution accurately.
- Describe what humans actually did to verify it.
- Use verification methods appropriate to the potential consequence.
- Record modifications, rejection, or failed verification honestly.
